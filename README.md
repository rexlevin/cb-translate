# 灵译 · cb-translate

基于 [Canbox 平台](https://rexlevin.github.io/canbox-pages/) 的轻量桌面翻译工具。界面简洁、开箱即用，适合日常随手翻译——翻译引擎为[百度翻译开放平台](https://fanyi-api.baidu.com/)（使用你自己的免费 API 密钥）。

[English Documentation](./README_en.md)

## 功能特性

- ⚡ **极速翻译** — 输入或粘贴文本，按下 `Ctrl+Enter` 即可出结果
- 🌍 **19 种目标语言** — 中文(简体/繁体)、英语、日语、韩语、法语、德语、西班牙语、俄语、葡萄牙语、意大利语、阿拉伯语、泰语、越南语、印尼语、荷兰语、波兰语、土耳其语、印地语等
- 🔎 **自动检测语言** — 源语言默认自动检测，结果上方会显示识别出的语言
- 🔄 **一键互换** — 点击方向按钮即可交换源语言与目标语言
- 📋 **一键复制** — 整段译文一键复制到剪贴板
- 🕘 **翻译历史** — 每次翻译成功自动本地保存；点击某条记录即可恢复原文、语言方向与译文
- ⚙️ **偏好设置** — 可自定义默认目标语言与历史上限（10 ~ 1000 条，默认 200）
- 🔒 **密钥安全** — 百度 APP ID / 密钥通过操作系统安全存储加密（Windows DPAPI / macOS Keychain / Linux libsecret），请求在主进程签名发出，明文不会落入渲染层
- 📐 **缩放与记忆** — 支持 `Ctrl+滚轮` / `Ctrl+=` / `Ctrl+-` / `Ctrl+0` 调整界面；窗口大小与缩放比例自动记忆

## 快速开始

### 1. 安装应用

通过 **Canbox 管理器**安装并启动灵译（在"应用仓库"添加仓库地址 `https://github.com/rexlevin/cb-translate`，或从应用目录中直接安装）。

### 2. 获取百度翻译 API 密钥

灵译使用**你自己的百度翻译密钥**发起翻译（不内置公共 key，用你的账号、走你的免费额度）：

1. 打开 [百度翻译开放平台](https://fanyi-api.baidu.com/)，注册并登录
2. 创建应用（选择"通用文本翻译"），记下 **APP ID** 和 **密钥**
3. 免费标准版有每月字符额度，日常使用通常足够

> 💡 提示：更安全的做法是为应用开启 **IP 白名单**。开启后仅限白名单内的 IP 调用（否则报错 `58000`）。

### 3. 在设置中完成配置

1. 打开灵译，点击右上角 **设置**
2. 在 **百度翻译** 一栏填入 APP ID 与密钥，点击 **保存**
3. 可选：修改 **默认目标语**、调整 **历史上限**

完成后即可开始翻译。

## 使用指南

### 翻译文本

1. 在原文框输入或粘贴文本（支持多行，单次最多 **6000 字符**，输入框左下角有字数统计）
2. 选择 **源语言**（默认"自动检测"）与 **目标语言**
3. 点击 **翻译** 按钮，或直接按 **`Ctrl+Enter`**

### 查看译文

- 结果区始终标注引擎来源（百度翻译）
- 开启自动检测时，结果上方会以"识别为…"显示实际检测到的语言
- 点击 **复制** 可将整段译文复制到剪贴板
- 长文本会按段落分行展示，与原文排版保持一致

### 翻译历史

点击右上角 **历史** 打开历史抽屉：

- 每次翻译成功自动本地保存，最新记录排在最前
- 点击某条记录 → 原文、语言方向与译文会回填到主界面，方便复用或继续编辑
- 可通过垃圾桶图标删除单条记录，也可点击 **清空** 一键清空（带确认提示）
- 超过设定上限时自动裁剪最旧的记录

## 设置项一览

| 设置项 | 说明 | 默认值 |
|---|---|---|
| 百度翻译 APP ID / 密钥 | 你的百度开放平台凭据（本地加密保存） | — |
| 默认目标语 | 启动应用时默认的目标语言 | 中文(简体) |
| 历史上限 | 历史记录最大条数（10 ~ 1000） | 200 |

## 快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl+Enter` | 翻译 |
| `Ctrl+1` | 聚焦原文输入框 |
| `Ctrl+滚轮` / `Ctrl+=` / `Ctrl+-` | 放大 / 缩小界面 |
| `Ctrl+0` | 恢复 100% 缩放 |

## 安全与隐私

- **凭据保护**：APP ID / 密钥在写入磁盘前会经操作系统安全存储加密（Windows DPAPI、macOS Keychain、Linux libsecret），渲染进程永远接触不到明文密钥。
- **请求方式**：翻译请求在主进程完成签名并直接发送给百度 API，不经过任何第三方服务器。
- **数据说明**：待翻译文本会按服务需要发送至百度进行翻译；翻译历史**仅保存在你的本机**。
- 若系统缺少安全存储后端，灵译会退化为本地明文保存，并在设置界面中明确给出警告提示。

## 常见问题

**Q: 提示"请先在设置中配置百度翻译 APP ID 与密钥"**
尚未配置密钥，请按上文[快速开始](#快速开始)完成配置。

**Q: 52003 / 未授权用户**
APP ID 填写错误或应用未通过审核，请到百度翻译开放平台控制台核对。

**Q: 54001 / 签名错误**
密钥与 APP ID 不匹配。请在设置中重新完整填写两项凭据。

**Q: 54004 / 账户余额不足或免费额度已用完**
免费版每月额度已用尽或账户余额不足。可等待额度重置或充值。

**Q: 58000 / 客户端 IP 不在白名单内**
百度应用开启了 IP 白名单，而当前 IP 未在白名单中。请把本机 IP 加入白名单，或关闭白名单。

**Q: 网络请求失败**
请检查网络连接后重试。单次请求 15 秒超时。

**Q: 译文语言方向不支持**
百度不支持该语言方向组合，请换用支持的源语言 / 目标语言。
